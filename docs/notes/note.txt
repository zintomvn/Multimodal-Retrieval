    + Save best result -> view nào điểm cao nhất thì lấy: best_score
    + Save average score: avg_score
    + RRF giữa các perspectives (ưu tiên frame có nhiều perspectives hơn -> cái này hơi xàm): view_rrf = Sigma of ( 1 / r_view) 
    + Tính Coverage (Frame được nhiều cách diễn đạt khác nhau cùng retrieve có khả năng relevant cao hơn): coverage = # views retrieving f / # total views
    => Tổng kết score: final_score = (
        0.58 * best.final_score
        + 0.24 * avg_score
        + 0.13 * view_rrf
        + 0.05 * coverage
    )
